# Retrieval worked example

Generated by `python3 -m orchestrator.retrieve_cli`, committed so the behaviour is
checkable without running anything. Regenerate with `make retrieve TASK="..."`.

Indexed **4 skills**, reading **4 version-ledger
entries** as the state history rather than tracking versions separately.

Scores are cosine over deterministic TF-IDF. `body` matches the skill's description,
applicability and rules; `sig` matches its declared signature, which is weighted higher
because it is what a skill author committed to rather than an incidental word in a rule.
`trust` is reported separately and never folded into the score: an untrusted skill can
still be the right skill to amend.
